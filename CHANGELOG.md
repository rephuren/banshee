# История изменений

## Не выпущено

### Добавлено
- движок Sigma (подмножество): выборки, модификаторы `contains`/`startswith`/`endswith`/`all`/`re`, ключевые слова, условия `and`/`or`/`not`/`N of`/`all of`; неподдерживаемое отклоняется с причиной (#1)
- `banshee sigma --rules DIR --events FILE [--min-level] [--json]`, события из JSONL или массива JSON, сводка техник ATT&CK по тегам (#1)
- четыре учебных правила в `rules/sigma` и примеры событий
- движок YARA (подмножество): текстовые, hex и regex-строки, условия, `filesize`, `uintN`, `N of`; неподдерживаемое отклоняется с причиной (#3)
- `banshee yara --rules DIR PATH [--json]`: сканирование файла или каталога без перехода по симлинкам, сводка техник из `meta` (#3)
- четыре учебных правила в `rules/yara` и пять безобидных образцов в `examples/samples`
